test-backend-ops harness

Runs llama.cpp's own tests/test-backend-ops in this browser. It executes each op on every registered backend and on the CPU backend in the same process, and compares the results, so a pass here is a numerical claim about the WebGPU kernels, not just evidence that they were reachable. Default filter is MUL_MAT_ID, the MoE expert FFN added by patches/0004.

The verdict below is computed here, not taken from the program. Its own n/n tests passed line and its exit status count only the cases it ran - NOT_SUPPORTED and SKIPPED are skipped before the counter, so a run that executed nothing still prints 0/0 tests passed and exits 0.
