Runtime-only harness

Requester and peer run in two tabs of this page and talk over a same-origin BroadcastChannel. No PeerJS, no WebRTC, no Hono: this exercises only the Runtime below the Web boundary, so a failure here is a Runtime failure. Passing here is not evidence that the Web integration works.

  recv_peer() only registers while Module._connbuf[fd] is empty, so a
  reused fd registering again is what shows the slot was cleared
  (patches/0001). The pointer value is not a signal: malloc may
  hand back the address it just freed. This shows the stale slot is gone; it is not a
