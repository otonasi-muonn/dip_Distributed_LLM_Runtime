test-backend-ops harness

Runs llama.cpp's own tests/test-backend-ops in this browser. It executes each op on the backend under test and on the CPU backend in the same process and compares the results, so a pass here is a numerical claim about the WebGPU kernels, not just evidence that they were reachable.

The verdict is computed here, not taken from the program. Its n/n tests passed line and its exit status count only the cases it ran - NOT_SUPPORTED and SKIPPED are skipped before the counter - so a run that executed nothing still prints 0/0 tests passed and exits 0. A pass here needs the expected number of cases to have run on one WebGPU section and all of them to be OK. Pass --test-file to supply that expected number; without it, completeness cannot be claimed.
